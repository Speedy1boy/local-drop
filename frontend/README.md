# Local Drop | Frontend

SPA-клиент для файлообменника, написанный на Angular с использованием современных подходов фреймворка (Signals, Standalone-компоненты, Control Flow).

## Особенности реализации
- UI-кит построен на Angular Material 3.
- Реализована кастомная светлая/темная тема с плавными синхронными переходами при переключении.
- Сложный Drag-and-Drop интерфейс через нативные HTML5 API (без тяжелых библиотек).
- Состояние синхронизируется с бэкендом через Socket.io.
- Вьювер медиафайлов написан с использованием Container Queries для корректного скейлинга при масштабировании.
- Адрес API определяется динамически через `window.location.hostname`, что позволяет открывать сайт с любых устройств в сети без перенастройки.

## Локальный запуск

Рекомендуется запускать клиент через корневой скрипт монорепозитория, чтобы корректно подтягивались общие типы.

Запуск из корня проекта:
```bash
npm run front
```

Сайт откроется на `http://localhost:4200`.

## Сборка

Сборка production-версии:
```bash
npm run build:front
```
