# Local Drop | Backend

REST API и WebSocket сервер приложения на базе NestJS. Отвечает за работу с файловой системой, бизнес-логику и управление базой данных.

## Архитектура
- **REST API:** Обработка CRUD операций, загрузки файлов (Multer) и выдачи статики.
- **WebSockets:** Гейтвеи для оповещения клиентов об изменениях в файловой системе и буфере обмена.
- **База данных:** PostgreSQL используется для хранения метаданных (размер, тип, иерархия папок). Физические файлы сохраняются на диск.
- **ORM:** Prisma для типизированного взаимодействия с БД.

## Подготовка базы данных

Перед первым запуском убедитесь, что база данных запущена, и накатите миграции:
```bash
npx prisma migrate dev
```

## Локальный запуск

Запуск осуществляется через скрипт в корне монорепозитория. 
```bash
npm run back
```

Сервер поднимется на порту `3000`. Папка для сохранения файлов (`uploads/`) создается автоматически в корне бэкенда.
