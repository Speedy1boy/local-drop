# Local Drop | Backend

REST API и WebSocket сервер приложения на базе NestJS. Отвечает за работу с файловой системой, авторизацию, бизнес-логику и управление базой данных.

## Архитектура
- **REST API:** Обработка CRUD операций, загрузки файлов (Multer) и выдачи статики.
- **WebSockets:** Гейтвеи для оповещения клиентов об изменениях в файловой системе, буфере обмена и заметках.
- **База данных:** PostgreSQL используется для хранения метаданных (размер, тип, иерархия папок, сессии, логи безопасности). Физические файлы сохраняются на диск в `backend/uploads`.
- **ORM:** Prisma для типизированного взаимодействия с БД.
- **Безопасность:** JWT-авторизация, ThrottlerGuard от частых запросов, автоматическая блокировка IP при подборе PIN-кода. Все лимиты вынесены в `src/rate-limits.config.ts`.

## Подготовка базы данных

Перед первым запуском убедитесь, что база данных запущена, и накатите миграции:
```bash
npm run db:migrate
```

Если папка `uploads` содержит файлы, но база данных пуста (например, после пересоздания), запустите синхронизацию:
```bash
npm run db:sync
```

## Локальный запуск

Запуск осуществляется через скрипт в корне монорепозитория:
```bash
npm run back
```

Сервер поднимется на порту `3000` и будет слушать все сетевые интерфейсы (`0.0.0.0`). Папка для сохранения файлов (`uploads/`) находится в `backend/uploads/` и создается автоматически.
