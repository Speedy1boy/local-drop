# Local Drop

Веб-сервис для обмена файлами, заметками и буфером обмена в локальной сети. Кроссплатформенная альтернатива AirDrop, работающая прямо в браузере. Проект реализован в виде монорепозитория (NPM Workspaces).

## Основные возможности
- **Файловый менеджер:** Загрузка, скачивание и удаление файлов. Поддержка Drag-and-Drop.
- **Иерархия папок:** Создание папок, навигация (хлебные крошки), перемещение файлов и папок перетаскиванием.
- **Общий буфер обмена:** Мгновенная синхронизация текста и ссылок между устройствами.
- **Заметки:** Создание и редактирование заметок с тегами.
- **Real-time:** Мгновенное обновление UI на всех клиентах через WebSockets.
- **Просмотрщик:** Встроенный полноэкранный viewer для фото и видео.
- **Админ-панель:** Управление активными сессиями, просмотр логов безопасности и заблокированных IP.
- **Безопасность:** Авторизация по PIN-коду, защита от брутфорса и спама с автоматическим баном IP.

## Стек технологий
- **Frontend:** Angular 18 (Standalone, Signals, Material 3).
- **Backend:** NestJS, TypeScript, Socket.io.
- **База данных:** PostgreSQL, Prisma ORM.
- **Инфраструктура:** Docker, Docker Compose.

## Быстрый запуск (Production / Домашнее использование)

Для запуска потребуется установленный Docker и Node.js.

1. Склонируйте репозиторий.
2. Установите зависимости и запустите проект одной командой:
   ```bash
   npm install && npm run all
   ```
3. Приложение будет доступно по адресу `http://localhost:4200` (или по IP машины в локальной сети).

## Локальная разработка

Проект использует NPM Workspaces для связывания фронтенда, бэкенда и общей библиотеки типов (`@local-drop/shared`).

### Подготовка
1. Установите зависимости в корне проекта:
   ```bash
   npm install
   ```
2. Соберите общие типы (важно делать это при любых изменениях в папке `shared`):
   ```bash
   npm run build:shared
   ```
3. Создайте файл `.env` в папке `backend` на основе шаблона `backend/.env.example`.

### Повседневный запуск

Поднимите базу данных в фоне (требуется Docker):
```bash
npm run db:up
```

Запустите Frontend и Backend одновременно в режиме watch:
```bash
npm run dev
```

- Frontend: `http://localhost:4200`
- Backend: `http://localhost:3000`

Для остановки базы данных:
```bash
npm run db:down
```

### Полный список команд

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск фронтенда и бэкенда в режиме разработки |
| `npm run all` | Полная сборка и запуск production-версии |
| `npm run build:all` | Сборка всех воркспейсов без запуска |
| `npm run build:shared` | Сборка только общей библиотеки типов |
| `npm run build:front` | Сборка только фронтенда |
| `npm run build:back` | Сборка только бэкенда |
| `npm run front` | Запуск только фронтенда (dev) |
| `npm run back` | Запуск только бэкенда (dev) |
| `npm run db:up` | Запуск PostgreSQL в Docker |
| `npm run db:down` | Остановка PostgreSQL |
| `npm run db:migrate` | Применение миграций Prisma |
| `npm run db:sync` | Синхронизация файлов из `backend/uploads` с базой данных |
| `npm run docker:up` | Полный запуск проекта в Docker |
| `npm run docker:down` | Остановка всех Docker-контейнеров |
```
